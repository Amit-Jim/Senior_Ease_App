# Senior-Ease App

**AI-powered mobile app for seniors** to stay independent, safe, and connected.

## Key Features
- Conversational **AI chat** (Google Gemini 2.5 Flash) with streaming responses
- **Voice input** for hands-free interaction
- **Emergency help** dialog with quick-dial contacts
- **Smart quick actions** for common senior tasks
- Accessible UI with large text, high contrast, and intuitive navigation

## Tech Stack
- **Frontend:** React 18, TypeScript, Vite, Tailwind CSS, Shadcn UI, Lucide React
- **Backend:** Lovable Cloud Edge Functions, Lovable AI Gateway
- **AI Model:** google/gemini-2.5-flash
